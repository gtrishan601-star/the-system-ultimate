THE SYSTEM V4.0 — MULTI-PAGE HUNTER INTERFACE

START
1. Extract this ZIP.
2. Open THE_SYSTEM_V3/index.html in Chrome to test.
3. For reliable install/offline support and browser notifications, host the folder on HTTPS (for example GitHub Pages), then open the hosted URL in Chrome and choose Install app / Add to Home screen.

NEW IN V4
- Separate mobile-style pages: Home, Quests, Gates, Skills, Items, Stats, Alerts and Profile.
- Attribute radar chart and seven-day XP bar chart.
- In-app notification centre for quest completion, level-ups, dungeon clears and skill unlocks.
- Optional browser notifications when permission is granted. Background delivery depends on browser/device support; this is not a remote push-notification service.
- Animated navigation, charts, glowing panels and system alerts.

FEATURES
- Player level, XP, E-to-S rank progression and four attributes.
- Daily/custom quests, weekly challenges, safe dungeons, skills, inventory, titles and achievements.
- JSON backup export/import and local browser save.

IMPORTANT
- This is a mobile-friendly Progressive Web App, not a signed Android APK.
- Progress is stored locally in this browser. Export a backup before switching versions, clearing data or changing devices.
- V4 reads the same local save key as V3. If you have important V2/V3 progress, export a backup first.
- Notifications require browser permission. Reliable PWA features require HTTPS hosting.
- The anime-inspired interface is original fan-style UI, not an official Solo Leveling app.
